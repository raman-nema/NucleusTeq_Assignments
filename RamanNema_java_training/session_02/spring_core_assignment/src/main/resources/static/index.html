User Service

The application is running. Use the endpoints below to read or create users.

  • GET /users returns all users as JSON.
  • GET /users/{id} returns one user by id.
  • POST /users creates a user from JSON.

Example request body for POST /users:

{
  "id": 3,
  "name": "Aman",
  "email": "aman@example.com"
}
