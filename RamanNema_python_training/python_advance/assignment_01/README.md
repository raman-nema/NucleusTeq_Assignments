## How to Run

### Clone the Repository

```bash
git clone https://github.com/raman-nema/NucleusTeq_Assignments.git
cd NucleusTeq_Assignments
```

### Run a Python Program

Navigate to the required folder and run the file:

```bash
python3 exception_handling/divide_numbers.py
```

Example:

```bash
python3 iterators_generators/fibonacci_generator.py
```

### Run Pytest Test Cases

Execute all test files:

```bash
python3 -m pytest
```

Run a specific test file:

```bash
python3 -m pytest testing_debugging/test_add_numbers.py
```
