## How to Run

1. Clone the repository.
2. Navigate to the `assignment_02` folder.
3. Install required libraries:

```bash
pip install numpy pandas matplotlib seaborn jupyter
```

4. Start Jupyter Notebook:

```bash
jupyter notebook
```


5. Open the desired notebook and execute the cells.

## Note:

 This assignment is implemented using Jupyter Notebooks and can be executed in either Jupyter Notebook or Visual Studio Code (VS Code) with the Python and Jupyter extensions installed.
