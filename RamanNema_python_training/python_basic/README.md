- Python introduction
- Python syntax and structure
- Variables and data types
- Control flow (if, for, while)
- Functions and modules
- Lists, tuples, dictionaries, sets
- Object Oriented Programming concepts
- File input/output

### Folder Descriptions

- **data_structure**: Programs demonstrating Python data structures (lists, tuples, dictionaries, sets)
- **file_handling**: Programs for reading, writing, and manipulating files
- **functions**: Examples of function definitions, parameters, and return values
- **introduction**: Basic introductory Python programs
- **loops**: Programs using for and while loops
- **modules**: Examples of importing and using Python modules
- **oop**: Object-oriented programming concepts (classes, inheritance, polymorphism, encapsulation)
- **operators_conditionals**: Programs demonstrating operators and conditional statements
- **variables_datatypes**: Programs exploring Python variables and data types

## Usage

1. Open a terminal.
2. Navigate to this folder.
3. Run Python scripts using `python filename.py` or `python3 filename.py`.

## Requirements

- Python 3.8 or higher
- No external libraries or third-party packages are required.
- All programs in this folder use Python's built-in features and standard library modules only.

## Note

- `__init__.py` files are intentionally omitted as this folder structure contains standalone training exercises and is not structured as a Python package.

## Goal

Build a strong foundation in Python by completing and reviewing the examples and exercises in this folder.
